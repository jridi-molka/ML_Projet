# Fraud Detection in Banking Transactions Using ML

## Installation
```
git clone <URL_DU_REPO>
cd fraud-detection
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Données
Télécharger `creditcard.csv` depuis kaggle.com/datasets/mlg-ulb/creditcardfraud
et le placer dans le dossier `data/`.
